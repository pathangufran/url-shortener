# URL Shortener

A production-ready URL Shortener inspired by Bitly and TinyURL.

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Redis
- Celery
- Docker
- Gunicorn
- Nginx
- AWS

## Features

- JWT Authentication
- URL Shortening
- Redirect Service
- Analytics
- Redis Caching
- Background Jobs
- Rate Limiting
- QR Code Generation
- Docker Deployment
- CI/CD
